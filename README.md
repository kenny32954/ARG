# ECHO-1: The Lost Frequency

> **Tune into the horror.**

ECHO-1 is a browser-first alternate reality game set around an impossible carrier in the fictional town of Ravenswood. Players investigate Jonah's disappearance, Herman Vale's escalating search, the abandoned G-7 receive annex, and the identity behind the voice on 101.1 MHz.

## Current build

The repository now contains a complete six-phase playable web path:

- **Phase 1 — First Contact**
  - simulated FM receiver
  - procedural WebAudio static and carrier tones
  - spectral waterfall
  - transmission capture archive
  - terminal-gated municipal records
  - exposure-based evidence recovery

- **Phase 2 — Signal Mapping**
  - fictional Ravenswood radio-direction-finding map
  - noisy azimuth correlation model
  - multi-relay triangulation
  - G-7 magnetic tape calibration
  - procedural tone recovery

- **Phase 3 — Jonah's Trail**
  - recovered desktop environment
  - draggable windows and virtual filesystem
  - deleted files and browser history
  - raw cache reconstruction
  - municipal microfilm reader

- **Phase 4 — Perception Drift**
  - signal-driven stability system
  - deterministic record mutation
  - grounding controls
  - invariant-event identification
  - Room 3 access reconstruction

- **Phase 5 — The Broadcaster**
  - recovered correspondence ordering
  - hidden carbon copy
  - archive authentication
  - voiceprint comparison

- **Phase 6 — The Last Transmission**
  - composite-signal reconstruction
  - final Jonah record
  - three persistent local endings

Progress is stored with browser `localStorage`. No external libraries or servers are required.

## Run locally

Open `index.html` directly in a modern browser, or serve the repository with any static HTTP server. WebAudio features require a user interaction before playback, as required by modern browsers.

## GitHub Pages

The project is static and is designed to run from the repository root on GitHub Pages. A `.nojekyll` marker is included so all folders are served as authored.

### Scheduled live mode

`/live/` is an optional release wrapper driven by `release-config.json`. The current schedule begins October 2, 2026 and opens a new phase every 14 days. Change only `startDate` to move the entire six-phase schedule; the normal repository root remains the unrestricted test build.

## Design rules

- Ravenswood, G-7, all infrastructure, identities, radio systems, records, and events are fictional.
- The project imitates radio investigation without transmitting on or interfering with real-world frequencies.
- No physical location or camera access is required.
- Core puzzle routes are discoverable through in-world records, source residue, encoded paths, and prior-stage outputs.
- Later routes are intentionally not linked from the repository landing page.
