# ECHO-1: The Lost Frequency

> **Tune into the horror.**

ECHO-1 is a browser-first alternate reality game set around a dead radio channel in the fictional town of Ravenswood. The player discovers fragments surrounding Jonah's disappearance and the person known only as **The Broadcaster**.

## Current build

Phase 1 foundation includes:

- simulated FM tuner and signal-strength model
- procedural radio static generated in-browser
- 101.1 MHz ECHO-1 signal behavior
- CRT / field-radio visual interface
- live waterfall display
- transmission capture log
- hidden source-level material for ARG investigation
- archive terminal for gated discoveries
- local progress persistence
- responsive desktop/mobile layout

No external libraries are required.

## Run locally

Open `index.html` directly, or serve the repository with any static HTTP server.

## GitHub Pages

This project is designed to run directly from GitHub Pages from the repository root.

## Planned structure

## Fiction / safety boundary

Ravenswood, its radio infrastructure, phone numbers, addresses, organizations, and broadcasts are fictional. The tuner imitates radio-investigation mechanics without transmitting on real-world frequencies.
